# Right-currency-converter
A simple and responsive currency converter built using HTML, CSS and JavaScript. It allows users to convert currencies using exchange rates retrieved from an external API.

## Features
- Convert between multiple international currencies.
- Fetch exchange rates through a REST API.
- Dynamic currency selection.
- Country flag updates.
- Swap currencies instantly.
- Input validation and error handling.
- Responsive design for different screen sizes.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await

## How to Run
1. Clone this repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Open `index.html` using Live Server.
